# ブランド

凪の配色とロゴの使い方。色の値は `tui/src/ui/theme.rs` の 1 か所に書く。ロゴ（`tui/src/ui/render/logo.rs`）は `BRAND_*` を読み、`assets/*.svg` は同じ 16 進を使う。`theme.rs` の `brand_colors_match_svgs` が、この 3 つの SVG と `BRAND_*` のずれを見つける。

## 色

ロゴの色（凪の海。昇る太陽と、青い水面）:

| 名前 | 16 進 | 役目 | Rust の定数 |
| --- | --- | --- | --- |
| 太陽（上） | `#FDE68A` | 太陽のグラデーションの上、`n` の点 | `BRAND_SUN_TOP` |
| 太陽（下） | `#F5B971` | 太陽のグラデーションの下 | `BRAND_SUN_BOTTOM` |
| 水平線 | `#93C5FD` | 水平線の線 | `BRAND_HORIZON` |
| 水面（上） | `#60A5FA` | 水面の映りの上。アプリのアクセントと同じ青 | `BRAND_WATER_TOP` |
| 水面（下） | `#3B4CCA` | 水面の映りの下 | `BRAND_WATER_BOTTOM` |
| 地 | `#0D1117` | ロゴを置く暗い地、アイコンの地 | `BRAND_GROUND` |

字の線は地に合わせる。暗い地は `#EEF0F5`（`logo-dark.svg`）、明るい地は `#16203A`（`logo-light.svg`）。

アプリの色（TUI）:

| 名前 | 16 進 | 役目 | Rust の定数 |
| --- | --- | --- | --- |
| アクセント | `#60A5FA` | 選択、今いる画面の印 | `ACCENT` |
| 進行中 | `#60A5FA` | 進行中の印 ◐ | `IN_PROGRESS` |
| 注意 | `#F0B860` | 目を向けてほしい印（今日来たタスク、優先度「高」） | `ATTENTION` |
| 締切切れ | `#F07878` | 締切を過ぎた | `DANGER` |
| 補助 | `#9696AC` | 小さい補助の文字 | `MUTED` |
| 控えめ | `#686880` | 区切り、案内 | `FAINT` |
| 選んだ行の地 | `#263454` | 選んでいる行 | `SELECTED_BG` |
| カーソルの行の地 | `#2E4670` | カーソルのある行 | `CURSOR_BG` |
| ポップアップの地 | `#181C28` | ポップアップ、サイドバー | `SURFACE` |
| 枠 | `#425470` | ポップアップの枠 | `BORDER` |

アクセント、注意、締切切れは、どの 2 つも CIE76 の色差が 25 以上ある。文字の色は `SURFACE` と `BRAND_GROUND` の上でコントラスト比 4.5 以上（`FAINT` は 3.0 以上）。どちらも `theme.rs` のテストが守る。

## ロゴの使い分け

- `assets/logo-dark.svg`: 暗い地に置く、字の入ったロゴ。
- `assets/logo-light.svg`: 明るい地に置く、字の入ったロゴ。
- `assets/icon.svg`: 正方形の場所（アプリのアイコン、プロフィール画像）。

## 余白と大きさ

- 余白は、ロゴの四方に太陽の半径と同じ幅をとる。
- 最小の大きさは、アイコンが 16 px、字の入ったロゴが幅 120 px。

## してはいけないこと

- 色を変える。上の表の 16 進だけを使う。
- 縦横を引き伸ばす。比率を保って拡大縮小する。
- 影を付ける。
- 写真の上に置く。
- 締切切れにアクセントの色を使う。締切切れは `DANGER` だけ。
