# ブランド

凪のマーク「接」と配色の使い方。色の値は `tui/src/ui/theme.rs` の 1 か所に書く。端末のロゴ（`tui/src/ui/render/logo.rs`）は `BRAND_*` を読み、`assets/*.svg` は同じ 16 進を使う。`theme.rs` の `brand_colors_match_svgs` が、3 つの SVG の色が下の表のとおりかを確かめる（SVG ごとに、使ってよい色の全部と比べる）。

## マーク「接」

ふたつの正方形が、角の一点だけで触れている。押し合わず、離れもしない釣り合い。

- 正方形は同じ大きさ。A を左上、B を右下に置く。
- B の左上の角が、A の右下の角に一点で触れる。重ねない。すき間もあけない。
- マークは正方形 2 つ分の幅と高さの正方形に収まる。座標で言えば、A は `(0, 0)–(50, 50)`、B は `(50, 50)–(100, 100)`。
- 端末でも同じ形で描く。サイドバーは 6×3 セル、ログインの画面は半ブロックで描き、最後のコマで角が一点で触れる（`logo.rs` のテストが確かめる）。

## ロックアップ（マークと `Nagi`）

マークの右に `Nagi` を置く。頭は大文字の N。コマンドの名前は小文字の `nagi` のまま。

- 字は Inter、太さ 580、字間 −0.022em。
- マークの高さは `Nagi` のキャップハイト（N の高さ）と同じ。マークの下の辺をベースラインに揃える。
- マークと語の間は、キャップハイトの 0.5 倍。マークの右の辺から、語の書き出しの位置（N の左の余白を含む）までを測る。
- 字の色は、暗い地で `#E6E9F0`、白い地で `#16203A`。

## ロゴの使い分け

- `assets/logo-dark.svg`: 暗い地に置くロックアップ。
- `assets/logo-light.svg`: 白い地に置くロックアップ。
- `assets/icon.svg`: 正方形の場所（アプリのアイコン、プロフィール画像）。`BRAND_GROUND` の角の丸い正方形のまん中に、マークだけを置く。

どの SVG も字を `<text>` で書かず、輪郭の形にしてある。フォントのない環境でも同じに見える。

## 余白と大きさ

- 余白は、マークの四方に正方形 1 つ分の幅をとる。アイコンもこの余白で組んである（512 の正方形に、幅 256 のマーク）。
- 最小の大きさは、アイコンが 16 px、ロックアップが幅 96 px。16 px のアイコンでは、正方形がちょうど 4×4 px になる。

## してはいけないこと

- 色を変える。上の表の 16 進だけを使う。
- 縦横を引き伸ばす。比率を保って拡大縮小する。
- 回す。正方形は A が左上、B が右下のまま。
- 正方形を離す、重ねる。角は一点だけで触れる。
- 影、光彩、グラデーションなどの効果を付ける。
- `Nagi` をほかのフォントで組む。
- 締切切れにアクセントの色を使う。締切切れは `DANGER` だけ。

## フォントの出典

SVG の `Nagi` は、Inter（Rasmus Andersson、<https://rsms.me/inter/>）の可変フォント 4.001 を、太さ 580・光学サイズ 32 に固定して輪郭にしたもの。Inter は SIL Open Font License 1.1 で配られている（<https://openfontlicense.org>）。
